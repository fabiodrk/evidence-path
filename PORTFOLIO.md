# Portfolio context

Evidence Path is a local prototype developed in the Digital Innovation Challenge 2026 project workspace. It builds on the related HRPG pilot concept. This repository packages the runnable implementation and its tests; it does not assert sole authorship of the broader challenge concept, group pitches, or supplied workflow materials.

The publication copy omits all saved candidate records, attachments, local access files, logs, reports, and machine-specific browser automation. Fictional demonstration records are generated by the application in a fresh local data folder.

Windows launchers were made portable. The original working project remains separate. No production deployment, assessment validity, or hiring effectiveness is claimed.
